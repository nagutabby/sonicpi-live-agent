# 調声メモ(NEUTRINO Tau で歌声を整える)

調声 = 歌声を作り直して良いテイクを選び、必要なら NEUTRINO が推定した中間ファイルを編集して続きの段階だけ作り直すこと。
NEUTRINO は `timing`(音素の時刻)→ `f0`(音高、10ms 刻み float32)→ `melspec`(100bin の対数メル、10ms 刻み float32)→ `wav` の順に推定する。`--skip-timing/--skip-f0/--skip-melspec/--skip-wav` で編集済みの段階を飛ばせる。
**wav は作るたびに位相が変わる**ので、調声の最後に1回だけ作る(`neutrino_tune.py` はそうしている)。

歌詞の書き方は `docs/lyric-guide.md`。この文書は歌声側(譜面の書き方、Tau のオプション、調声)。

## 1. 譜面(MusicXML)側でできること
NEUTRINO は譜面から歌い方を自動で推定する。譜面で効くものと効かないもの(公式: [MusicXMLについて](https://studio-neutrino.com/articles/neutrino-cli-musicxml/))。

| | 要素 | このプロジェクトでの書き方 |
|---|---|---|
| 効く | 音高・音符の長さ・フレーズ長 | `[歌詞, 音名, 拍]` |
| 効く | タイ | 4つ目の印 `"tie"`(次の音符は同じ音名・歌詞は空) |
| 効く | ブレス記号。ブレスか休符で囲まれた区間が1フレーズで、生成はフレーズ単位 | 印 `"br"`(その音符のあとにブレス) |
| 効かない | 調号・スラー・スタッカート・アクセント・強弱・速度 | 書かない |

- 細かい休符でフレーズを刻むと情報が減って平坦になりやすい。実際の楽譜のように音符をつないで、フレーズ(息継ぎ)を意識して書く(`lyric_check.py` が警告する)。
- 1音符に母音を2つ以上入れると、区切らずに繋いで歌う傾向がある。1音符1モーラにする。
- 歌詞の記号: `っ`(促音)/ `ー`(直前の母音を伸ばす)/ `'`(母音脱落。「す'」は子音のみ)。

## 2. Tau のオプション(`neutrino_sing.py` が渡す)
| 指定 | NEUTRINO | 効果 | 聴いて確かめること |
|---|---|---|---|
| `--model` | モデルディレクトリ | 声質(MERROW/NAKUMO/REINA/RUNO/SOMA)。モデルごとに利用条件がある | 声の高さ・音域が曲に合うか |
| `--style-shift K` | `-k` | -5〜5。「2」で2つ上のキーの歌い方、「-2」で2つ下の歌い方。声の高さそのものは変えない | 歌い方の勢い・明るさ(未確認。聴いて決める) |
| `--transpose N` | `-f` | 半音単位のトランスポーズ | キーが合うか |
| `--support S` | `-S` | 主モデルの声質のまま、別モデルの歌い方のニュアンスを混ぜる | 声質が崩れないか・歌い方の違い |
| (作り直し) | — | 生成のたびに波形が変わる。気に入らない箇所はリテイクで改善することがある | 同じ箇所のテイク違い |

手本は `~/neutrino/Run.sh`(基本)、`Run_support_model.sh`(サポートモデル)、`Run_single_phrase.sh`(1フレーズだけ作り直す `-p`。このプロジェクトのスクリプトには未実装)。

## 3. `neutrino_tune.py`(自然さを残す調声)
| 指定 | 編集する段階 | 値の目安 | 効果 | 副作用 |
|---|---|---|---|---|
| `--pitch-lock` | f0 | 0.3(natural) / 0.6(tight) | 音高を譜面の音に寄せる強さ。1 で完全固定 | 大きいと人間味が消え、ケロケロ感が出る |
| `--glide-ms` | f0 | 80 / 60 | 音符の頭で元の滑らかな入り(しゃくり)を残す長さ | 短いと音程が階段状になる |
| `--smooth` | f0 | 1 / 3 | f0 の移動平均(フレーム数) | 大きいとビブラートと音符の頭が鈍る |
| `--consonant-scale` | timing | 0.9 / 0.8 | 子音の長さの倍率(母音の頭は動かない) | 小さいと子音が聞こえない |
| `--hf-boost` | melspec | 0 / 0 | 約 5kHz 以上を持ち上げる(対数値) | 大きいとシャリつく・ノイジー |
| `--cons-boost` | melspec | 0 / 0.3 | 子音区間の約 2kHz 以上を持ち上げる | 同上 |
| `--model` `--support` `--style-shift` `--transpose` | (推定時) | 作成時と同じ値 | 再推定の声質・歌い方を揃える | |

`--preset natural` は表情(ビブラート・ゆらぎ)を残して外れた音程と長い子音だけを少し直す設定、`tight` は速いパッセージやハモリ向けに音程をしっかり寄せる設定。まず natural で作り、足りなければ1つだけ動かす。まず**リテイク**で足りないか確かめてから使う。

## 4. 結果の読み方(エージェントは聴けない)
`neutrino_tune.py` が出す2つの数値で判断する。
- **譜面の音高からのずれ(セント)**: 素の声は約 70。0 に近いほど機械的、大きすぎると外れて聞こえる。100 セント = 半音。ビブラートが深いほど増えるので、ずれが大きい = 悪い、ではない(聴いて確かめる)。
- **4kHz 以上の比**: 数%が目安。10% を超えるとシャリつく可能性が高い。低すぎると s・k・t の子音がこもる。
- `wav_stats.py` で、ピーク(-2dBFS 前後)と長さ(拍数 × 60/BPM)を見る。
聴いて確かめる箇所: ブレスの位置の自然さ / 子音の立ち上がり(ka・ta の頭)/ 長い音の母音と音程の安定 / フレーズ終わりの切れ方 / 高域のシャリつき。

## 5. 手順(1フレーズ)
```
uv run scripts/lyric_check.py work/vocals/NN_x.json
uv run scripts/neutrino_sing.py work/vocals/NN_x.json            # → NN_x_v1.* と NN_x_v1_clip.wav
uv run scripts/neutrino_sing.py work/vocals/NN_x.json            # リテイク(→ NN_x_v2.*)
uv run scripts/neutrino_tune.py work/vocals/NN_x_v2 --preset natural   # → NN_x_tuned_v1.* と _clip.wav
```
`_clip.wav` は頭の1小節の無音を捨てて譜面の拍数で切ってあり、`sample` を譜面の拍数だけ `sleep` する `live_loop` に置くと小節線に揃う。

利用許諾: 出力(wav・f0・melspec)を AI・機械学習による音声変換・合成の入力や学習データにしない。
