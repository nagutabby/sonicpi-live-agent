# 歌詞の書き方(NEUTRINO で歌わせる)

歌詞は**意味のある日本語**を基本とする。この文書は、NEUTRINO で歌わせるときの書き方と、作詞の工夫のメモ。
**[公式・調査]** は NEUTRINO の公式資料や調査で確かめたもの、**[一般論]** は作詞でよく言われる工夫で、このプロジェクトでは裏取りしていない(聴いて確かめる)。

## 1. 書き方の決まり(NEUTRINO)
- **[公式・調査]** 歌詞は、ひらがな(またはカタカナ)で、1音符に1モーラ(拗音「きょ」は1モーラ)。日本語は原則として1音符に1モーラが対応する。
- **[公式・調査]** 発音どおりに書く。「わたしは」→「わたしわ」、「きょうも」→「きょおも」、助詞の「へ」→「え」、「を」→「お」。
- **[公式・調査]** 記号: `っ`(促音)/ `ー`(直前の母音を伸ばす)/ `'`(母音脱落。「す'」は子音のみ)。
- **[公式・調査]** 1音符に母音を2つ以上入れると、区切らずに繋いで歌う傾向がある。
- **[公式・調査]** ブレス記号か休符で囲まれた区間が1フレーズ。ブレスは息継ぎの位置に置く(`br`)。細かい休符で刻むと平坦になる。
- 英語は歌えない。かな近似(例: "love" → 「らぶ」)にする。

`uv run scripts/lyric_check.py work/vocals/NN_x.json` が、1モーラ・助詞・小節またぎ・細かい休符・ブレスなしの長いフレーズを検査する。

## 2. 歌詞を曲に合わせる工夫
| 工夫 | 何をするか | 使うところ |
|---|---|---|
| **モーラ数を合わせる** [一般論] | 旋律の音符の数 = 歌詞のモーラ数。余る(字余り)なら音符を割る、足りない(字足らず)なら音を伸ばすか休符にする | 旋律を先に作る曲 |
| **長い音は開いた母音に** [一般論] | 2拍以上の音符は「あ・お」など口が開く母音にすると伸ばしやすい。「い・う」は細くなりやすい(聴いて確かめる) | 伸ばす音、サビの頂点 |
| **速い音符は軽い音に** [一般論] | 16分音符の連続は、子音が重い語(濁音・破裂音の連続)で詰まって聞こえやすい。同じ母音の連続やラ行・ナ行で流れやすい | 速いフレーズ |
| **強拍に意味のある語** [一般論] | 拍の頭(1拍目・3拍目)に、伝えたい語の頭の音を置く。助詞は弱拍に | Aメロ・Bメロ |
| **フックの繰り返し** [一般論] | サビに、タイトルになる短い語を置いて繰り返す(調査で、サビにタイトル語を置くと曲に統一感が出るとされていた) | サビ |
| **母音で韻を踏む** [一般論] | フレーズの終わりの母音をそろえる(「あ・お」で終わる等) | 行末、掛け合い |
| **説明しすぎない** | 説明が多い歌詞は、聴き手が感情移入する余地を奪う(調査より) | 全体 |
| **息継ぎの位置** [一般論] | 句点・読点の位置に `br` か休符。1フレーズは息が続く長さ(`lyric_check.py` は16拍超で警告) | 全体 |

## 3. 調声との関係
- 譜面側で効くのは、音の長さ・タイ・ブレス。歌い方の強弱は書いても効かないので、リテイク・`--style-shift`・`--support` で作り分ける(`docs/vocal-tuning.md`)。
- 言葉が聞き取りにくいときは、(1)音符を伸ばしすぎない (2)子音の連続を避ける (3)`neutrino_tune.py --consonant-scale / --cons-boost` を1つだけ動かす、の順に試す。
- 歌詞の聞き取りやすさは聴かないと分からない。`speak_phrase.py` で歌詞を同じタイミングで読み上げた wav と聴き比べると、拍のはまりを確かめやすい。

## 4. 例(ひらがなの書き方)
| 日本語 | 入力 | 理由 |
|---|---|---|
| わたしは | わ・た・し・わ | 助詞「は」→「わ」 |
| きょうも | きょ・お・も | 「う」の長音は「お」。拗音は1モーラ |
| ほしを | ほ・し・お | 助詞「を」→「お」 |
| がっこう | が・っ・こ・お | 促音は1音符 |
| そらへ | そ・ら・え | 助詞「へ」→「え」 |
